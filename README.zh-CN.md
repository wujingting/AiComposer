# AI 构图助手

[English](README.md) | **中文** | [日本語](README.ja.md)

在设备上运行的摄影指导：看着画面告诉你构图、光线、对焦哪里有问题、怎么改，并用 AI 美学模型（CLIP + LAION）打分。全部离线运行在手机或电脑上。

| 产品 | 是什么 | 用来 |
|---|---|---|
| **AI构图助手**（`app-sony`） | 通过 Wi-Fi 连接索尼 a6000 的 Android App：实时指导、参数建议、一键应用、自动快门 | 用索尼相机拍照 |
| **AI构图（手机）**（`app-phone`） | 用手机自己的摄像头，同样的实时指导 | 用手机拍照 |
| **AI照片打分**（`app-score`） | 给已经拍好的照片打分，标出精选和相似照片，逐张解释并建议裁剪 | 在手机上挑片、修图 |
| **电脑端挑片工具**（`tools/photo_picker`） | Python 工具：给整个文件夹打分（JPG + 索尼 ARW），去掉连拍重复，复制最好的照片 | 在电脑上整理一次拍摄 |

三个 App 共用一个库（`core`）：同样的规则、AI 模型和界面组件，在那里修一个 bug，所有 App 都生效。电脑挑片工具也用同一个 AI 模型和打分方式。

界面语言跟随系统：中文、日语，其他语言一律显示英文。App 横屏、竖屏都能用，跟随系统的自动旋转设置。

下面先详细介绍索尼相机版（其中指导引擎、AI 模型和界面这些大部分也适用于手机版），再介绍其他产品。

## 功能（索尼相机版）
| 功能 | 说明 |
|---|---|
| 实时取景 | 索尼 Camera Remote API 的 Liveview 流 |
| 三分线 + 构图评分 | 主体到最近三分点的距离、贴边、头顶空间、水平线，综合 0~100 分 |
| 主体识别 | ML Kit 人脸检测 + 物体检测（离线），黄框 = 人脸，青框 = 物体，粗框 = 主体 |
| 构图提示 | 「把人物放到三分点：相机往右转、往下压」 |
| 水平仪 | 自动找画面里的水平线，显示倾斜角度 |
| 场景识别 | 人像 / 风景 / 夜景 / 动体 / 特写 / 日常随拍 |
| 参数建议 | 光圈、快门、ISO、曝光补偿 + 理由（逆光、过曝、防抖、动体） |
| 一键应用 | 把建议参数写进相机（受转盘档位限制，见下） |
| **AI 美学评分** | CLIP ViT-B/32 + LAION 美学打分头，约每秒 1 次 |
| **AI 场景识别** | 同一个 CLIP 特征做零样本分类，比规则判断更准（动体、暗光仍用规则） |
| **AI 构图** | 在画面里搜索 19 个候选框，用紫色虚线框标出美学分最高的构图，并提示怎么移动 |
| **预留裁剪** | 镜头不够长时，设定后期要裁剪的比例和画幅；构图按白框（预计成片）评估，安全快门、ISO 上限自动收紧 |
| 自动快门 | 综合分（构图规则分 + 美学分）连续达标约 0.75 秒自动拍，两次间隔 ≥ 4 秒 |
| **方向箭头** | 取景画面边缘的黄色大箭头告诉你相机往哪转；构图到位时轻振一次（最多 4 秒一次） |

## 界面
- **横屏**：左边取景，右边面板。**竖屏**：上面取景，下面面板。
- 面板从上到下：
  1. **提示条**：大号综合分（附场景）+ 最重要的 3 个问题的短句（比如「人物在左边被切」），每条带严重程度色条。高度固定，内容变化时下面的按钮不会跳动。完整建议在体检清单里。
  2. **「指导」页**：体检清单、建议参数、相机当前参数、AI 美学。这些内容会实时变化。
  3. **「设置」页**：自动快门阈值、镜头焦距、预留裁剪、已忽略的规则。
  4. **底部操作栏**（位置固定）：拍照 / 应用建议 / AI 构图，自动快门开关，连接 / 断开。
- 取景画面上只画图形（三分线、识别框、水平仪、方向箭头等），文字提示不会挡住画面。
- 为户外设计：字号大；中性灰的背景（不影响你判断照片颜色）；只有一种强调色：**黄色 = 该做的事**（主按钮、当前选项、箭头），绿 / 橙 / 红 = 好 / 注意 / 问题。三个 App 共用这套配色和字号（`core/ui/Theme.kt`）。

## 编译运行（第一次）
1. 安装 **Android Studio**（Windows / Mac 都行），首次启动按向导装好 SDK。
2. File → Open → 选择 `AiComposer` 文件夹 → 等右下角 Gradle 同步完成（第一次要下载依赖，10～30 分钟，需要联网）。
   - 如果提示 "Upgrade Android Gradle Plugin"，**先选不升级**。
   - 如果提示缺少 SDK 35，点提示里的链接安装即可。
   - **Gradle JDK 选 JDK 21**（Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK）。新版 Android Studio 自带的 JDK 是 25，Gradle 8.11 不支持。
3. 菜单 Build → **Make Project**，看底部 Build 窗口有没有红色错误。
4. 手机开启「开发者选项 → USB 调试」，用 USB 线连电脑，顶部选中你的手机，在 ▶ 左边的运行配置里选要装的 App（**app-sony** = 索尼相机版，**app-phone** = 手机摄像头版，**app-score** = 照片打分 App），点 ▶ Run。
5. 跑单元测试：命令行 `gradlew.bat test`（Mac 用 `./gradlew test`），或者在 Android Studio 里右键 `core/src/test` → Run Tests（选 Gradle 方式运行）。

### 编译报错时
把 Build 窗口里**第一个红色错误**（带文件名和行号的那一行，以及下面几行）复制下来。
往往修一个错误后面一串都会消失，所以每次只需要看最前面的几个。

## 摄影指导引擎（规则库）
`coach/` 目录下约 45 条规则，分几类，每条都会给出「问题 + 怎么改」：

| 类别 | 规则 |
|---|---|
| 构图 | 主体位置（三分点 / 识别对称居中）、主体被切、主体大小、视线和运动方向留白、穿头、背景杂乱、主体不突出、边缘干扰、画面平衡、水平 |
| 光线/曝光 | 整体太暗/太亮（告诉你按顺序拧哪个旋钮：快门 → 光圈 → ISO，守住安全快门和 ISO 上限）、逆光、过曝/死黑、脸部过曝、光比过大（DRO/HDR）、硬光/顶光、白平衡和混合光、雪地沙滩、暗光 |
| 对焦/参数 | 快门够不够快、ISO 噪点、景深（用人脸大小估算距离，多人合影算前后景深）、焦点是否在主体上、手抖、对焦模式、裁剪后像素 |
| 人像 | 闭眼、表情、头顶空间、眼睛在上三分线、关节处裁切（姿态检测）、近拍人脸变形、歪头 |
| 风景/建筑 | 地平线在正中、天空比例、前景空荡、竖线歪斜/仰拍汇聚 |
| 日常随拍 | 文字被切、文字歪了、画面没有重点（好几个抢眼的东西）、再靠近一点、颜色反差太平；光影、引导线、抓拍时机、拍动物、换视角等建议 |
| 美学 | CLIP 美学分 |

- 严重程度：问题（扣 25）> 注意（扣 12）> 提示（扣 4）> 建议（不扣分）> ✓
- 分项分数 = 100 × e^(−该项扣分/60)，分成**构图 / 光线 / 技术**三项
- 总分 = 三项加权平均（构图 50%、光线 25%、技术 25%）；有美学模型时再和美学分按 6:4 混合；有闭眼、糊片这类严重问题时最高 60 分。权重都在 `coach_config.json` 的 `total.*` 里
- **根本原因分组**：同一原因引起的问题只扣一次分（比如「背景乱」「主体不突出」「主体太小」算一组），其余标注「同一原因」
- **时间平滑**：问题在最近 1.5 秒内出现 60% 以上才报告，消失也要降到 30% 以下才撤掉，提示不会闪
- **自动快门**：看构图分（+ 美学分）；当前瞬间有人像或技术上的「问题」（闭眼、会糊、景深不够）时不拍，光线问题不拦（后期能救）
- 提示条只用短句显示最重要的 3 条，「指导」页的体检清单显示全部和完整建议
- 加新规则：在 `coach/*Rules.kt` 里写一个 `Rule`，加进 `all` 列表；显示的文字用 `tr(中文, 日文, 英文)` 写三种语言，另外给提示条写一个三语短句 `short`

### 调整阈值（不用重新编译）
所有阈值都在配置文件里。App 第一次启动时会导出到手机：
`Android/data/com.example.aicomposer/files/coach_config.json`
用 USB 连电脑或手机文件管理器打开修改，**重启 App 生效**。每一项的含义见 `coach/CoachConfig.kt` 里的注释。
删掉这个文件再重启，就会恢复默认值。
除了规则阈值，这里还有 `ai.threads`（美学模型用的 CPU 线程数，默认 2；越多越快但越热）和方向箭头、振动用的 `guide.*`。

### 规则冲突和「故意的」
- 有些规则会给出相反的移动方向（比如三分法让你往左、视线留白让你往右）。引擎按优先级只保留一条：
  视线/运动留白 > 头顶空间 > 关节裁切 > 主体被切 > 眼睛位置 > 三分点。让位的那条会降为「建议」，不扣分。
- 体检清单里每个问题旁都有「故意的」按钮：点了之后，**在当前场景下**忽略这条规则（比如你就是想居中构图）。
  被忽略的规则列在「设置」页的「已忽略的规则」里，可以随时恢复。

### 用到的本地模型
| 模型 | 用途 |
|---|---|
| ML Kit 人脸检测（含五官、睁眼/笑容、转头角度） | 人像规则、景深估算、视线留白 |
| YOLOX-S 物体检测（80 类：人、车、电车、动物、食物…，可选，见下） | 主体（认得出是什么）；也用来核对人体姿态，避免把花草当成人 |
| ML Kit 物体检测 / 图像标签 | 没装 YOLOX 时的主体；场景 |
| ML Kit 人体姿态（33 个关键点） | 看不到脸的人、关节处裁切、全身判断 |
| ML Kit 主体分割 | 通用主体、画面平衡（需要 Google Play 服务，首次自动下载） |
| 显著性检测（传统算法，每帧） | 找出画面里最「跳」的东西当主体，任何题材都适用；判断画面是否简洁 |
| ML Kit 文字识别（日文 + 英文） | 招牌、标语当主体候选；文字被切、文字歪了 |
| CLIP 看点（约每 2 秒） | 把画面分 9 块，找内容上最有意思的区域（橙色虚线框），用它从候选里挑主体 |
| CLIP + LAION（可选，见下） | 美学评分、场景、AI 构图 |

## 安装物体检测模型（一次性，推荐）
```bash
python tools/get_detector_model.py
```
下载 YOLOX-S（旷视，Apache-2.0 许可，约 36MB）到 `core/src/main/assets/detector.onnx`，然后重新编译 App。
- 手机较旧、觉得卡：`--size tiny`（约 20MB，快但准确度低一些）；想更准：`--size m`（约 97MB，慢约 3 倍）
- 不装也能用，会退回 ML Kit 物体检测（只认 5 个大类，认不出车、动物等）
- 识别门槛在 `coach_config.json` 的 `detector.min_score`（默认 0.35）

## 安装 AI 美学模型（一次性，在电脑上做）
模型约 96MB，没有放进 Git 仓库，需要用脚本生成：
```bash
pip install torch open_clip_torch onnx onnxruntime
python tools/export_clip_model.py
```
脚本会下载 CLIP 和 LAION 打分头，转换成 ONNX 并做 int8 量化（只量化 MatMul，卷积层保持原样，这样手机上的 ONNX Runtime 才能运行），最后输出到 `core/src/main/assets/`：
- `clip_image.onnx`（约 96MB）
- `clip_meta.json`

最后会打印「特征一致度」，接近 1（> 0.98）就说明转换没问题。然后重新编译 App 即可。
- 想要更高精度：`python tools/export_clip_model.py --no-quant`（约 350MB，速度会慢一些）
- 不装模型 App 也能用，只是 AI 美学相关功能会显示「未安装」。模型加载失败时，「指导」页会显示具体原因。

### 关于分数
- 美学分是 LAION 标准（大约 1~10）。取景画面分辨率低，又经过压缩，所以分数会比成片低，**主要看相对高低**。
- 换算成 0~100 的范围在 `AestheticModel.kt` 的 `NORM_LOW` / `NORM_HIGH` 里设置，实拍后可以按需调整。

## 使用（索尼相机版）
1. a6000：MENU → 应用程序 → **智能遥控内嵌**（不是「发送到智能手机」）。
2. 手机连接相机显示的 Wi-Fi（DIRECT-xxxx），提示「无法访问互联网」时选**保持连接**。
3. 打开 App，点「连接相机」。
4. 在「设置」页把「镜头焦距」设成你当前用的焦距（防抖计算用）。

### 让参数建议更准
- 相机设置：**实时取景显示 → 设置效果：开**（取景亮度才会反映参数）。
- **ISO 设成具体数值**（不要 AUTO），App 才能推算出建议的 ISO。

### 「应用建议」的限制
a6000 的拍摄模式由机身转盘决定，App 改不了：
- 改**光圈**：转盘要在 A 或 M
- 改**快门**：转盘要在 S 或 M
- 改 **ISO / 曝光补偿**：P / A / S 档一般都可以（M 档不能改曝光补偿）

设置不了的项目，App 会提示你应该转到哪个档位。

## 预留裁剪模式（索尼相机版，35-50mm 不够长时）
**默认是「自动」**：App 根据主体大小判断要不要裁剪、保留多少：
- 人物：脸的高度约占成片 15% 算合适；其他主体：约占成片面积 12% 算合适
- 主体比这个小，就按比例预留裁剪（最多到 50%）；风景、没有主体时不裁
- 需要裁剪但焦距还没到 50mm 时，会先提示「镜头拉到 50mm 端」（相机不会把焦距告诉 App，拉到后要在「设置」页把焦距设为 50）
- 这些标准在 `coach_config.json` 的 `autocrop.*` 里，可以按自己的习惯调整

也可以在「设置」页切到「手动」，自己选择**保留比例**（80% / 70% / 60% / 50%）和**成片画幅**（3:2、4:3、1:1、4:5、16:9）：
- 画面上会出现**白框**（预计成片范围），框外变暗，三分线画在白框里
- 构图评分和移动提示都按白框计算，提示目标是让白框放得下、主体落在白框的三分点上
- 裁剪相当于放大画面：50mm 保留 60% ≈ 83mm（全画幅等效约 125mm）。安全快门按等效焦距计算，ISO 上限也会降低（60% → 1250）
- 显示裁剪后还剩多少百万像素，低于 8MP 时提醒
- 「AI 构图」会在画面里搜索 25 个位置，用紫框标出**最好看的裁剪位置**，拍完按紫框裁就行

## 手机摄像头版（app-phone）
同样的指导也可以直接用手机自己的摄像头，不需要索尼相机。它是一个单独的 App（「AI构图（手机）」），可以和索尼版同时安装。
- 布局和索尼版一样，规则、AI 美学、AI 构图、方向箭头、自动快门也都一样（自动快门开关放在按钮那一行，给「指导」页多留空间）
- 点一下取景画面：对焦并按那里测光；变焦和曝光补偿在「设置」页
- 照片保存在 `Pictures/AiComposer`
- 手机光圈固定、曝光自动，所以没有「建议参数 / 应用建议」；曝光建议会改为提示调曝光补偿。快门速度和 ISO 是从相机读出来的，快门和 ISO 的规则照常工作。景深规则不适用（它是按 a6000 的 APS-C 传感器算的），会自动跳过

## 照片打分 App（app-score）
第三个 App「AI照片打分」：在手机上给已经拍好的照片打分。
- 用系统的照片选择器选图（不需要存储权限），或者在相册里选好照片后「分享」给它
- 按美学分（约 1~10）排序；最好的 20% 标 **★ 精选**，连拍和相似照片标 **相似**（规则和电脑端挑片工具相同）
- 点开一张照片：构图叠加层、名次、EXIF 里的拍摄参数（快门、光圈、ISO、焦距）和完整的体检清单；**AI 构图** 会画出建议的裁剪框（紫框）和裁剪后能到的分数
- 建议是按「照片已经拍好了」来写的：后期怎么修，或者下次怎么拍

## 电脑端挑片工具
同一个美学模型也可以在电脑上给整个文件夹的照片打分（支持 JPG 和索尼 ARW），去掉连拍的相似照片，把最好的复制到另一个文件夹：
```bash
python tools/photo_picker/pick_photos.py D:/Photo/2026-11-17 --top 30
```
详见 [tools/photo_picker/README.zh-CN.md](tools/photo_picker/README.zh-CN.md)。

## 设置保存、性能监控、测试
- 焦距、预留裁剪、自动快门阈值、忽略的规则都会自动保存，下次打开自动恢复
- 性能监控：「指导」页显示每次分析耗时和手机温度。分析太慢或手机发热时自动降频（每秒 4 次 → 2 次 → 1 次），很热时暂停 AI 美学分析
- 单元测试：`core/src/test/` 下有规则、景深计算、裁剪、冲突协调、多语言等测试，在电脑上跑，不需要手机

## 常见问题
| 现象 | 原因 / 处理 |
|---|---|
| 连接失败 | 相机没开「智能遥控内嵌」；或手机自动切回了家里的 Wi-Fi |
| 连上了但没画面 | 看提示条和「指导」页的提示信息 |
| 参数建议里 ISO 显示 AUTO | 相机 ISO 是 AUTO，把它设成具体数值 |
| 水平仪不显示 | 画面里没有足够明显的水平线（正常） |
| 发热/耗电 | 分析每秒约 4 次，太慢或太热时会自动降频；很热时暂停 AI 美学分析 |
| 显示「美学模型加载失败」 | 后面会显示具体原因；常见原因是用旧版脚本导出的模型，重新运行导出脚本即可 |
| Gradle 同步报错，只显示一个版本号（如 25.0.x） | Gradle JDK 用了 Java 25，改成 JDK 21 |
